# [309. Best Time to Buy and Sell Stock with Cooldown](https://leetcode.com/problems/best-time-to-buy-and-sell-stock-with-cooldown/)
Medium


You are given an array prices where prices[i] is the price of a given stock on the ith day.

Find the maximum profit you can achieve. You may complete as many transactions as you like (i.e., buy one and sell one share of the stock multiple times) with the following restrictions:

After you sell your stock, you cannot buy stock on the next day (i.e., cooldown one day).
Note: You may not engage in multiple transactions simultaneously (i.e., you must sell the stock before you buy again).

 

Example 1:
```
Input: prices = [1,2,3,0,2]
Output: 3
Explanation: transactions = [buy, sell, cooldown, buy, sell]
```
Example 2:
```
Input: prices = [1]
Output: 0
``` 

Constraints:

- 1 <= prices.length <= 5000
- 0 <= prices[i] <= 1000

## Solution
```java
class Solution {
    // Memo map: key = "index-buyingFlag", value = max profit from this state
class Solution {
    private Map<String, Integer> dp = new HashMap<>();

    public int maxProfit(int[] prices) {
        return dfs(prices, 0, true);
    }

    private int dfs(int[] prices, int i, boolean canBuy) {

        // No more days left
        if (i >= prices.length) {
            return 0;
        }

        String key = i + "-" + canBuy;

        // Already calculated this state
        if (dp.containsKey(key)) {
            return dp.get(key);
        }

        int result;

        if (canBuy) {

            // Option 1: Buy stock today
            int buy = dfs(prices, i + 1, false) - prices[i];

            // Option 2: Skip today
            int skip = dfs(prices, i + 1, true);

            result = Math.max(buy, skip);

        } else {

            // Option 1: Sell today
            // Skip next day because of cooldown
            int sell = prices[i] + dfs(prices, i + 2, true);

            // Option 2: Keep holding stock
            int hold = dfs(prices, i + 1, false);

            result = Math.max(sell, hold);
        }

        dp.put(key, result);
        return result;
    }
}

```

## Complexity Analysis
```
- Time Complexity: O(N)
- Space Complexity: O(N)
```
